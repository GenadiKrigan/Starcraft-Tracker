# Starcraft TMG Tracker

A simple companion tool for Starcraft Tabletop Miniatures Game players. Track your victory points, manage your supply, and conquer the sector with ease. This app is designed to replace paper tracking and keep your focus where it belongs: on the battlefield.

---

## Key Features

### Tactical Setup
Customize every match to yours preferences:
*   **Variable Rounds:** Play short skirmishes or epic wars by setting the total round count.
*   **Supply Management:** Set initial supply and growth rates (Supply Increase per round).

### Battle Dashboard
*   **Dual Player Tracking:** Dedicated, color-coded cards for Blue and Red players.
*   **Dynamic Supply:** Current/Max supply display that updates automatically as the game progresses.
### Smart Persistence
*   **Resume Anytime:** Game state is automatically saved on every change. 
*   **Auto-Resume:** Accidentally closed the app? One tap from the start screen puts you exactly where you were.

### Tabletop UX
*   **Locked Landscape:** The game board is locked to landscape mode for optimal visibility on the table.
*   **Stay Awake:** Built-in "Keep Screen On" functionality ensures your phone doesn't dim during long strategy discussions.

## How to Install (v1.0)

1.  **Download:** Open this repository on your Android device and navigate to the Releases section.
2.  **Get the APK:** Download the file named `Starcraft_TMG_Tracker_v1.0.apk`.
3.  **Permissions:** 
    *   Open the `.apk` file from your downloads.
    *   If prompted, go to **Settings** and enable **"Allow from this source"** for your browser or file manager.
4.  **Launch:** Tap **Install**, then **Open**, and select **New Game** to begin your conquest!
